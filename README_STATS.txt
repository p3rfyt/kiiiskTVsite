kiiiskTV — готовая система статистики

ЧТО ДОБАВЛЕНО
- favicon Image/favicon.png подключён ко всем HTML-страницам;
- в профилях трофеев по умолчанию видно только название турнира;
- детали трофея открываются при наведении;
- общая статистика игрока: матчи, победы, поражения, Winrate, K/D, KDA, Kills, Deaths, Assists;
- Winrate по картам с победами/поражениями/матчами;
- последние матчи в профиле;
- стартовая статистика для уже сыгранной истории;
- постоянные ID игроков: статистика работает даже у игрока без страницы профиля;
- обновлённая локальная админка;
- история матчей;
- внешние CDN-библиотеки для статистики/графиков убраны.

КАК ДОБАВИТЬ НОВЫЙ МАТЧ
1. Открой admin.html в Google Chrome или Microsoft Edge на компьютере.
2. Нажми «Открыть matches.js» и выбери data/matches.js из этого проекта.
3. Заполни дату, турнир, карту, команды, счёт и игроков.
4. Введи K/D/A для каждого игрока.
5. Нажми «Добавить матч».
6. Нажми «Сохранить данные».
7. В GitHub Desktop сделай Commit и Push origin.

КАК ДОБАВИТЬ СТАРУЮ СТАТИСТИКУ
1. В админке нажми «Открыть initial-stats.js».
2. Выбери игрока или введи новый ID.
3. Укажи общие матчи, победы, поражения, ничьи и K/D/A.
4. При необходимости добавь стартовые данные по картам.
5. Для каждой карты победы + поражения + ничьи должны совпадать с количеством матчей.
6. Нажми «Сохранить стартовую статистику», затем «Сохранить данные».
7. GitHub Desktop → Commit → Push origin.

КАК РАБОТАЕТ ИТОГОВАЯ СТАТИСТИКА
Итог = initial-stats.js + все матчи из matches.js.
Ничего вручную в профилях менять не нужно.

Если у игрока нет статистики, на сайте отображается только:
«Статистики пока нет.»

Постоянный ID игрока хранится в data/players.js. Страница профиля может быть добавлена позже — уже накопленная статистика останется привязанной к тому же ID.
