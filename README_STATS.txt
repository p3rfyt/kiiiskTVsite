kiiiskTV — ручная статистика игроков

Теперь статистика профиля вводится прямо в HTML-файле конкретного игрока.
Автоматическая система матчей больше не используется для отображения этой статистики в профилях.

Где менять статистику
----------------------
Открой, например:
Players/perf.html

В самом низу файла найди блок:
window.KIIISK_MANUAL_PROFILE_STATS = {
    ...
};

Менять нужно только числа внутри этого блока.

Поля
-----
matches — общее количество матчей
wins    — количество побед
kills   — суммарное количество киллов за все матчи
deaths  — суммарное количество смертей за все матчи
damage  — суммарный нанесённый урон за все матчи

Сайт автоматически считает:
- общий Winrate = wins / matches * 100
- K/D = kills / deaths
- средние киллы = kills / matches
- средний урон = damage / matches
- поражения = matches - wins

Статистика по картам
--------------------
Для каждой карты:
Mirage:  { matches: 0, wins: 0 }
Inferno: { matches: 0, wins: 0 }
Ancient: { matches: 0, wins: 0 }
Nuke:    { matches: 0, wins: 0 }
Dust2:   { matches: 0, wins: 0 }
Anubis:  { matches: 0, wins: 0 }
Cache:   { matches: 0, wins: 0 }

maps.matches — сколько раз игрок сыграл эту карту
maps.wins    — сколько раз выиграл эту карту

Сайт автоматически показывает:
- количество сыгранных карт;
- количество побед и поражений;
- Winrate по карте;
- красивую полосу Winrate.

Пример
------
window.KIIISK_MANUAL_PROFILE_STATS = {
    matches: 20,
    wins: 14,
    kills: 420,
    deaths: 350,
    damage: 18500,
    maps: {
        Mirage:  { matches: 8, wins: 6 },
        Inferno: { matches: 6, wins: 4 },
        Ancient: { matches: 4, wins: 3 },
        Nuke:    { matches: 2, wins: 1 }
    }
};

Графики
--------
Графики результатов турниров сохранены. Данные для существующих графиков находятся в:
data/profile-charts.js

Если для игрока нет данных графика, блок графика автоматически скрывается.
