kiiiskTV — система Perf рейтинга

Что изменено:
- statistics.html теперь использует общую шапку и подвал сайта.
- В навигации: «Kiiisk рейтинг» — страница players.html, «Perf рейтинг» — statistics.html.
- Perf рейтинг показывает отдельную карточку каждого игрока, а не общую сумму по всем игрокам.
- В карточке игрока: Perf /100, матчи, W/L, K/D, Winrate, Kills, Assists.
- Последние матчи оставлены отдельным блоком внизу.
- На всех HTML-страницах добавлена ссылка на Perf рейтинг.
- На профилях игроков добавлен динамический блок «Perf статистика».
- Kiiisk рейтинг не пересчитывается этой системой и сохраняет существующие Points.

Perf score:
- 40% — K/D (с потолком 2.5)
- 30% — Winrate
- 20% — KDA (с потолком 3.0)
- 10% — средние Assists за матч (с потолком 10)

Максимум: 100.
Формула является отдельным показателем формы/результативности и не заменяет Kiiisk рейтинг.

После добавления матча через admin.html данные сохраняются в data/matches.js.
GitHub Pages только отображает эти данные; сервер и сторонние сервисы для расчёта не нужны.
